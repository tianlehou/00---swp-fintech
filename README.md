# Fiado Digital (prototipo)

Landing Angular con la misma estructura de motion y layout que **Genkidamás**, mostrando el pitch de `resumen.md`.

## Arranque

```bash
npm install
npm start
```

Abre [http://localhost:4200](http://localhost:4200).

## Convenciones del repo

Reglas y skills de agente en `.cursor/` (copiados desde el proyecto Genkidamás). Detalle de producto en `PRODUCT.md`.
